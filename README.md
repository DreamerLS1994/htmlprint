# htmlprint
网页打印助手

## **使用指导：**

**插件安装参考：**

**设置--》更多工具--》扩展程序**

![](https://cdn.jerrycoding.com/media/ckeditor_upload/2020/06/11/image_THR3qJA.png)

**右上角开启开发者模式：**

![](https://cdn.jerrycoding.com/media/ckeditor_upload/2020/06/11/image_Nmy8QrP.png)

**点击加载已解压的扩展程序，选择解压后的压缩包 安装即可。**

![](https://cdn.jerrycoding.com/media/ckeditor_upload/2020/06/11/image_22lIgBp.png)

解压后的文件夹

![](https://cdn.jerrycoding.com/media/ckeditor_upload/2020/06/11/image_2TQQ8wR.png)

**想打印某个网页，就点击右上角打印网页即可。**

![](https://cdn.jerrycoding.com/media/ckeditor_upload/2020/06/11/image_1D9NVTu.png)

**直接会弹出打印界面，保存为pdf即可。**

![](https://cdn.jerrycoding.com/media/ckeditor_upload/2020/06/11/image_ybK8igi.png)
