# 使用说明

## 基本流程

1. **进入选择模式**：点击浏览器工具栏中的扩展图标，鼠标变为十字光标，页面顶部出现工具栏。
2. **悬停预览**：鼠标经过可打印内容块时，元素显示蓝色虚线框。
3. **点击选择**：点击后该区域变为绿色实线框，左上角显示选择序号（①②③…）。
4. **调整粒度**：`Alt` + 点击向上一层扩大范围；`Shift` + 点击精确选择鼠标所在的最内层元素。
5. **多区域**：可继续选择其他区域，每个区域在打印时单独占一页，按选择顺序排列。点击工具栏中的「已选 N 个」可展开列表，拖拽调整顺序或单项移除。
6. **打印**：点击工具栏「打印」或按 `Enter`，在打印预览中确认后输出 PDF 或纸质文档。
7. **结束**：按 `Esc` 或点击「退出」，选择框与工具栏会被移除。

再次点击已选中的区域可以取消该区域的选择。选择或移除区域后，按 `Ctrl+Z` 可以撤销。

## 工具栏

| 按钮 | 功能 |
|------|------|
| 打印 | 打印当前所有选中区域，按顺序分页 |
| 已选计数 | 点击展开已选区域列表，支持拖拽排序、单项删除 |
| 清除 | 取消全部选择，当前页面状态不变 |
| 帮助 | 打开本说明文档 |
| 检查更新 | 从 GitHub Releases 获取最新版本信息 |
| 退出 | 退出选择模式 |

## 快捷键

| 按键 | 功能 |
|------|------|
| `Enter` | 打印当前选中内容（有选中区域时） |
| `Ctrl+Z` | 撤销上一次选择操作 |
| `Esc` | 退出选择模式 |

快捷键仅在选择模式下生效。焦点在输入框、文本域等可编辑元素内时，`Enter` 与 `Ctrl+Z` 不会触发扩展操作。

## 打印前的自动处理

选中内容在打印前会做以下处理，以便尽量完整地输出：

- 点击页面上的「展开更多 / 阅读全文」类按钮，移除 `max-height` 与 `collapsed` 限制。
- 将 `data-src`、`data-original` 等懒加载图片还原为真实地址，并去掉 `loading="lazy"`。
- 还原 `srcset` 与 `<picture><source>` 的懒加载地址。
- 将 `canvas` 画布内容转换为图片，避免图表打印为空白。
- 同步输入框、复选框、单选框、下拉框和文本域的当前填写内容。
- 打印样式会重置 `overflow: hidden`、`position: fixed/sticky`、`transform`、`clip-path` 等可能造成截断的属性。
- 图片宽度限制在页面宽度内，高度不超过 22cm，并保持原始比例。
- 标题不孤立在页尾，表格行、图片、代码块避免跨页拆分。

## 常见问题

### 点击扩展图标没有反应

`chrome://`、`edge://` 等浏览器内置页面不允许扩展注入脚本。请切换到普通网页，刷新后再试。

### 打印结果有空白页

选中的区域可能包含空容器。尝试选择更具体的内容块（例如直接点击文章正文或表格）。

### 打印时样式丢失

部分站点在运行时用 JavaScript 注入样式，克隆内容时可能无法完全复制。可以刷新页面后重试，或在打印预览中检查。

### 打印后页面排版变乱

打印前的「自动展开」会修改页面元素。关闭打印预览后刷新页面即可恢复。这是当前版本的已知限制。

### 支持哪些浏览器

所有 Chromium 内核浏览器：Chrome、Edge、Brave、360 浏览器等。Firefox 与 Safari 未做适配。

## 卸载

在 `chrome://extensions/` 中找到「网页打印助手」，点击「移除」。
